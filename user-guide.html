JOIN AND REQUEST A SONG

Performer

Use your phone to join the room and add a song to its queue.

  1. 1

    Join the room

    Open the Performer portal and check the Room availability list below Request access. It shows each room name and Room ID; green Available means open, while red Occupied means in use. Scan the QR code on the display or enter its Room ID to join.

  2. 2

    Sign in

    Enter your username and password. New performers can request an account from the sign-in screen. Account and password-reset requests are sent only when an admin is active. If no admin is online, use the Facebook contact link shown in the message.

  3. 3

    Search and reserve

    Search by song title or artist, then select Reserve on the right result. Use the star to save or remove a favorite.

  4. 4

    Follow your place in line

    Check Reserved Songs to see the room queue. Playback and volume controls affect the shared display.

If the room is full or its time expires, use Request another room or Request Additional Time when shown. If no admin is online, the room request cannot be sent; use the Facebook link shown for help.

SHARED SCREEN

Karaoke Display

Set up the shared screen so performers can join the correct room.

  1. 1

    Open the display on a TV or second screen

    Open Karaoke Display in a separate browser or device. It automatically assigns an available room; check that its room name and Room ID match the performers' screen.

  2. 2

    Show the QR code and current song

    Performers scan the QR code to join. Use Full Screen for a clearer view of the current and next songs. They can enter the Room ID if scanning is unavailable.

  3. 3

    Use Clear Queue carefully

    Clear Queue removes queued songs from the active room. It requires an admin password and confirmation.

QUICK FIXES

Troubleshooting

Try these checks for common performer and display issues.

The QR code will not scan

Allow camera access in your browser, move closer to the screen, or enter the Room ID shown on the display.

I cannot join the room

Check that the Room ID matches the display and that the room has space. If the room is full or its time has ended, use the request option shown on screen.

I cannot find or reserve a song

Try a shorter search using the song title or artist. Confirm that you joined the intended room and that the display is available.

There is no sound on the display

Check the TV or device volume, browser audio, and the room mute and volume controls on the Performer screen.
