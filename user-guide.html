SD KARAOKE / MAGSIMULA RITO

Gabay sa paggamit

Piliin ang papel mo sa karaoke. Sundan ang mga hakbang para makakonekta, makapagpareserba ng kanta, at mapatakbo ang display.

Piliin ang portal Buksan ang display

Kailangan ng performer ng room QR o Room ID at aprubadong account. Kung wala ka pang account, mag-request ng access sa sign-in screen.

01

KUMANTA AT MAGPA-RESERVE

Para sa Performer

Gamitin ang phone para sumali sa room at idagdag ang kanta sa pila.

  1. 1

    Kumonekta sa room

    Sa home, piliin ang Karaoke Performer. I-scan ang QR code sa TV, o piliin ang Enter Room ID at ilagay ang ID na nakikita sa display.

  2. 2

    Mag-sign in

    Ilagay ang username at password kapag nakakonekta na sa room. Kung wala ka pang account, mag-submit ng account request at hintayin ang approval ng administrator.

  3. 3

    Maghanap at magpa-reserve

    Sa Search & Reserve, hanapin ang title o artist. Pindutin ang Reserve sa tamang kanta para idagdag ito sa room queue. Gamitin ang star para itabi o alisin sa Saved favorites.

  4. 4

    Subaybayan ang pila

    Tingnan ang Reserved Songs habang naghihintay na patugtugin ng host ang kanta. Ang mute, volume, at play/pause controls ay nakaaapekto sa shared display ng room.

Kapag puno ang room o tapos na ang oras nito, gamitin ang Request another room o Request Additional Time kung ipinakita sa screen. Hintayin ang approval bago magpatuloy.

02

MAGHANDA AT MAG-MANAGE

Para sa Administrator

Gamitin ang sidebar para lumipat sa mga bahagi ng admin dashboard.

  1. 1

    Gumawa ng karaoke room

    Buksan ang Karaoke Rooms, ilagay ang room name, at pindutin ang Add Room. Ibahagi sa performers ang QR code o Room ID na ipinapakita sa karaoke display.

  2. 2

    Pamahalaan ang accounts

    Sa User Management, suriin ang account requests at aprubahan o tanggihan ang mga ito. Gamitin ang Add New User para gumawa ng account; piliin lamang ang Admin role para sa pinagkakatiwalaang tagapamahala.

  3. 3

    Ayusin ang room requests

    Sa Room Requests, piliin ang Room Requests o Time Extensions, saka aprubahan o tanggihan ang pending request. Sa History, piliin ang mga row o ang checkbox sa table header para piliin ang lahat sa kasalukuyang page, at pindutin ang Delete selected kung kailangan.

  4. 4

    Kontrolin ang display

    Sa Karaoke Display Control, puwedeng i-enable o i-disable ang lahat ng display o isang napiling room. Kapag naka-disable, pumili ng announcement para makita ng performers ang dahilan.

03

SCREEN PARA SA LAHAT

Para sa Karaoke Display

Magbukas ng hiwalay na browser o screen para sa kasalukuyang kanta at QR.

  1. 1

    Buksan sa TV o pangalawang screen

    Bisitahin ang Karaoke Display page. Awtomatiko itong mag-a-assign ng available room; tiyaking tugma ang room name at Room ID sa screen ng performers. Iwan itong bukas habang ginagamit ang karaoke.

  2. 2

    Ipakita ang QR at kanta

    I-scan ng performers ang QR sa screen para sumali. I-full screen para mas madaling makita ang pinapatugtog at ang susunod na kanta. Kung hindi ma-scan, gamitin ang Room ID.

  3. 3

    Gamitin nang maingat ang Clear Queue

    Inaalis ng Clear Queue ang mga nakapilang kanta sa aktibong room. Gamitin lamang ito kapag talagang kailangang linisin ang pila. Hihingi ito ng admin password at kumpirmasyon bago magpatuloy.

04

MABILIS NA TULONG

Kapag may problema

I-check muna ang mga ito bago muling kumonekta.

Hindi gumagana ang QR code

Payagan ang camera access sa browser. Kung hindi pa rin ma-scan, ilagay ang Room ID na nakasulat sa display.

Hindi ako makapag-sign in

Tiyaking tama ang Room ID at credentials. Para sa bagong performer account, mag-request ng access at hintaying aprubahan ito ng administrator.

Hindi lumalabas ang kanta o hindi makapag-reserve

Suriin kung nakakonekta ka sa tamang room at kung available ang display. Kapag puno o sarado ang room, sundin ang request na ipinapakita sa performer screen.
